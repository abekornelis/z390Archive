This zip archive contains the following files:

The main design document:
- zVSAM_design.txt

Five sample dataset dumps that were created manually
so they may contain contain some typos and some later
changes to the design document have not been refelcted
in these files. So there will be some differences.
Still, these give a good impression of what we have in mind.
- zVSAM_ESDS_F.txt   Sample dump of ESDS dataset with F records
- zVSAM_ESDS_FS.txt  Sample dump of ESDS dataset with FS records
- zVSAM_ESDS_V.txt   Sample dump of ESDS dataset with V records
- zVSAM_ESDS_VS.txt  Sample dump of ESDS dataset with VS records
- zVSAM_KSDS_F.txt   Sample dump of KSDS dataset+index with F records

Two dataset dumps, generated by the new zRepro facility
and the associated dump program. One set of files for:
- MY02DATA           Sample dump of ESDS dataset with F records
- MY08DATA           Sample dump of KSDS dataset+index with F records

For the MY02DATA dataset we have the following set of files:
- MY02DATA.DDR       Mapping of data areas used
- MYFILE02.DDD       Full Data Dump mapped to field names
- MYFILE02.DMD       Plain Hex Dump of the dataset
- MYFILE02.DTA       Binary copy of the dataset
- MYFILE2F.TXT       Input data used to load the dataset

For the MY08DATA dataset we have the following set of files:
- MY08DATA.DDR       Mapping of data areas used
- MY08INDX.DDR       Mapping of data areas used
- MYFILE08.DDD       Full Data Dump of data component mapped to field names
- MYFILE08.DDI       Full Data Dump of index component mapped to field names
- MYFILE08.DMD       Plain Hex Dump of the data component
- MYFILE08.DMI       Plain Hex Dump of the index component
- MYFILE08.DTA       Binary copy of the data component
- MYFILE08.IDX       Binary copy of the index component
- MYFILE8F.TXT       Input data used to load the dataset
